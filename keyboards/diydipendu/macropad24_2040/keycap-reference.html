MacroPad24 — keycap reference

Print at 100% scale with “fit to page” / scaling switched off. Each square is one 1u DSA cap on 19.05 mm pitch, so a correctly printed grid lays over the pad exactly — check by measuring one row: six keys should span 114 mm.

Dashed, italic — inherited from layer 0, so these keys do the same thing on every layer.
● — has a long-press action. Bottom-right: hold 1.5 s for a soft reset. The key to its left: hold 1.5 s to turn the screen off or on.
Layer N — steps through the layers: 0 → 1 → 2 → 3 → 0.
